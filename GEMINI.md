# Git Workflow Rules

- **Always Push to Git**: Whenever you finish making code, configuration, or asset changes in this repository, always stage the relevant files (`git add`), create a clear and concise commit (`git commit -m "..."`), and push the changes to the remote Git repository (`git push`).
- Before pushing, verify that the project builds cleanly and that no unintended temporary files, build artifacts (`.next/`, `node_modules/`), or secrets are staged.
